About This Project

This project was created as part of a web development assignment focused on loading and displaying data dynamically with JavaScript.

The goal was to display the first 50 Airbnb listings from a JSON file using the Fetch API and async/await. Each listing includes information such as the property name, description, amenities, host information, price, and images.

How It Was Built

The original dataset was obtained from Inside Airbnb for the Boston area. The data was provided as a CSV file, so it was converted into a smaller JSON file containing the first 50 listings and only the fields needed for this project.

JavaScript fetches the JSON file and dynamically creates each listing card in the page. Additional features were added, including ratings, review counts, links to the Airbnb listing and host profile, and responsive styling for different screen sizes.
