Important Tags in HTML

Important Tags for SEO

SEO (Search Engine Optimization) is the process of improving a webpage so search engines can better understand its content and show it in relevant search results.
Using the right tags is important because they provide information about the page, such as its title, description, and how search engines should treat it.

  • <title> - Defines the page title shown in search results.
  • <meta name="description"> - Provides a short description of the page.
  • <meta name="robots"> - Gives instructions to search engine crawlers.
  • <link rel="canonical"> - Identifies the preferred URL for a page.

10 Important Tags for HTML

HTML tags are the basic building blocks of a webpage.
They tell the browser what each piece of content represents, such as a heading, paragraph, image, link, or section.
Using the right tags also helps organize the page and makes the structure easier to understand.

The 10 most important HTML tags for me are:

  • <a> - Creates hyperlinks to other pages, sections, files, or external websites.
  • <p> - Defines a paragraph of text.
  • <h1> to <h6> - Define headings with different levels of importance, from the main heading to smaller subheadings.
  • <section> - Groups related content into a meaningful section of the page.
  • <img> - Displays an image on the webpage and can include alternative text for accessibility.
  • <meta> - Provides information about the webpage, such as its description, character encoding, or viewport settings.
  • <main> - Identifies the main and unique content of the webpage.
  • <title> - Defines the title of the webpage shown in the browser tab and used by search engines.
  • <div> - Creates a general block-level container used to group and organize elements.
  • <span> - Creates an inline container used to group or style small parts of text or other inline content.

The Box Model

The CSS Box Model describes how every HTML element is represented as a rectangular box.
It is composed of the content, padding, border, and margin.
Understanding these parts is important because they control the size of an element and the space inside and around it.

Here is an example of how the Box Model can be shown. We use variations of margin, padding, and border.

BORDER

First, we change only the border.

Border is the visible line that surrounds an element's content and padding. Its thickness, style, and color can be customized.

0px 5px 10px

MARGIN

Now we change the margin.

Margin is the transparent space outside an element's border. It controls the distance between that element and nearby elements.

0px 5px 10px

PADDING

Finally, we change the padding.

Padding is the transparent space between an element's content and its border. It gives the content more room inside the element.

0px 5px 10px

Understanding the Examples

  1. 16px: This example uses an absolute size. The text is displayed at 16 pixels regardless of the font size defined in its parent.
  2. 1.5em: This is relative to the inherited font size. In this example, the parent list has a font size of 20px, so 1.5em becomes 30px (20 × 1.5).
  3. 1.5rem: This is relative to the root font size of the page, not to the parent element. If the root font size is 16px, 1.5rem is approximately 24px.
  4. 18pt: Points are an absolute unit commonly associated with printed documents, where a predictable size is useful.
  5. 150%: A percentage is relative to the inherited font size. With a parent size of 20px, 150% produces a font size of 30px.
  6. 2vw: This unit is relative to the width of the browser window. The font size changes when the viewport becomes wider or narrower.

CSS Positioning

CSS positioning controls where elements appear on a webpage and how they behave in relation to other elements or the browser window. Different positioning options are useful for normal content flow, small adjustments, placing elements inside containers, or keeping elements visible while scrolling.

  • Static: This is the default position. The element stays in the normal flow of the page and is placed where the HTML structure defines it.
  • Relative: The element keeps its original space in the page, but it can be moved from that position using properties such as top, right, bottom, or left.
  • Absolute: The element is removed from the normal document flow and is positioned relative to its nearest positioned ancestor. Because it no longer reserves its original space, it can overlap other elements.
  • Fixed: The element is positioned relative to the browser window and stays in the same place even when the user scrolls. It can also overlap other content because it is removed from the normal document flow. On this page, fixed positioning is used for the "Back to top" button so it remains visible while navigating through the page.
Static: normal page content that does not need special positioning.
Relative: an element that needs a small adjustment from its original position.
Absolute: an element placed in a specific position inside a container.
